# 範例提示詞

## 基礎文章轉 PPT

```text
請使用 codex-ppt skill，把 /path/to/article.md 做成 10 頁左右的中文 PPT。受眾是內部技術團隊。
```

## 論文轉口試 PPT

```text
請使用 codex-ppt skill，把這篇論文做成 12 頁中文口試 PPT。風格偏科研口試，結構包括研究背景、方法、實驗、結果、侷限和總結。論文中的模型架構圖和主要實驗結果圖必須保留在對應頁面中。
```

## 指定視覺風格

```text
請使用 codex-ppt skill 產生 PPT。視覺風格參考我上傳的這份 PDF：大標題、強留白、黑白灰主色、少量紅色強調，整體像商業雜誌專題頁。請詳細閱讀我提供材料中的每一頁圖片，確保瞭解其風格，然後仿照其風格進行產生。
```

## 指定內建風格

```text
請使用 codex-ppt skill，把這份材料做成 10 頁 PPT。請使用內建的「手繪技術解說風」，用手繪線條、結構化示意圖、輕量標註和清晰的概念拆解來呈現內容，適合技術原理講解和知識科普。
```

也可以把風格名換成「清爽專業風」「學術口試風」「資料儀表板風」「電子墨水雜誌風」「創意雜誌風」等內建風格。

## 指定頁數和素材

```text
請使用 codex-ppt skill，把這份材料做成 15 頁 PPT。第 4 頁使用 architecture.png，第 9 頁使用 benchmark-results.png。
```

## 修改單頁

```text
第 6 頁資訊太密，標題不夠清楚。請只重新產生第 6 頁，保持整套 PPT 的風格不變，把內容拆成更清晰的三段結構。
```

## 儲存風格到個人風格庫

```text
這套 PPT 的視覺風格我很喜歡。請把它儲存到 codex-ppt 的個人風格庫裡，方便以後重複使用。說明裡包含配色、字型氣質、版式規則、插畫/圖表風格和適用場景。
```
